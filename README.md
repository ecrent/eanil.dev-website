# eanil.dev

Source code for my personal website and blog at [eanil.dev](https://eanil.dev).

## Stack

- [Vue 3](https://vuejs.org/) + [Vite](https://vitejs.dev/) — framework and build tool
- [vite-ssg](https://github.com/antfu-community/vite-ssg) — static site generation
- [UnoCSS](https://unocss.dev/) — utility CSS
- [unplugin-vue-markdown](https://github.com/unplugin/unplugin-vue-markdown) — Markdown as Vue components
- [Giscus](https://giscus.app/) — comments via GitHub Discussions
